# 数据可视化色彩搭配工具

基于《[如何制作和谐的数据可视化色彩搭配](https://qiaoqiaotang.notion.site/c0aafdbddbf143ae9bc614d0e44506d4)》方法论的配色工具：输入品牌色，基于 **OKLCH 色彩空间**生成同明度和谐色阶（品牌色、对比色、邻近色、分裂互补色、三联色、方形调色），并按固定规则自动生成可用于数据可视化图表的搭配方案。

## 功能

- **品牌色 / 基础色**：支持 HEX / RGB / HSL / LCH / OKLCH / LAB 多格式输入与取色器
- **OKLCH 色阶**：品牌色与 10 个和谐色各生成 10 级色阶，🔒 锁定各自基准色所在的一阶
- **单色色彩工具包**：每个色彩抽取 6 色（A 系列 3 阶 + Tint / Tone / Shade），TTS 强度随品牌色明度带自适应（亮 / 中 / 深三档），也支持手动固定或随机
- **搭配方案生成**：单色系 / 多色系（自由跨方案选 2–4 色）/ 双品牌色三种模式，含规则①②③、顺序随机、优选与暗色版
- **图表预览**：环形图 / 柱状图 / 折线图实时预览配色效果
- **一键导出**：复制 HEX / CSS 变量 / JSON

## 运行

单文件零依赖，直接用浏览器打开 `index.html` 即可。

本地开发（可选，带禁用缓存响应头，改代码后刷新必为最新）：

```bash
python3 server.py
# 浏览器访问 http://localhost:8741
```

## 方法论

1. 输入品牌色 / 基础色；
2. 在 HSL 色彩空间计算对比色、邻近色、分裂互补色、三联色、方形调色；
3. 所有色彩转化为 OKLCH 色彩空间 —— 明度更统一、色相恒定（明亮区间蓝色系不偏紫），色彩更和谐；
4. 基于品牌色生成和谐色（Lightness 限定 5–95），每个颜色生成 10 个色阶（A 100 → A 10），锁定各自的基准色阶；
5. 抽取颜色，按特定规则、顺序进行搭配：同一色彩的【品牌色 + TTS 色调】用于单色系；不同色彩的【品牌色 + TTS 色调】用于多色系；双品牌色为 A 品牌色 + B 品牌色直接搭配。
